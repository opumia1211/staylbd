================================================================================
PRODUCT ATTRIBUTES ও CATEGORY ATTRIBUTES – কী এবং কীভাবে ব্যবহার করবেন
================================================================================

১) Product Attributes
   লিংক: /sajaladminopu/attributes

   কী কাজ:
   - এখানে আপনি সেই সব "অ্যাট্রিবিউট" তৈরি ও ম্যানেজ করবেন যেগুলো প্রোডাক্টে ব্যবহার হয়।
   - উদাহরণ: Size (S, M, L), Color (Red, Blue), Storage (64GB, 128GB), RAM ইত্যাদি।

   প্রতিটি অ্যাট্রিবিউটের ফিল্ড:
   - Name: অ্যাট্রিবিউটের নাম (যেমন: Size, Color)
   - Slug: ইউনিক আইডি (ইংরেজি ছোট অক্ষর, যেমন: size, color)
   - Type: Select = ড্রপডাউন, Color = রঙ, Text/Number = টেক্সট বা সংখ্যা
   - Values: কমা দিয়ে অপশন (যেমন: S, M, L, XL বা Red, Blue, Green) – Type Select/Color এর জন্য
   - Sort Order: কত নম্বরে দেখাবে
   - Status: Active/Inactive

   এই পেজে যা করতে পারবেন:
   - অ্যাট্রিবিউট যোগ (Add Attribute), এডিট, ডিলিট, Enable/Disable
   - Type/Status দিয়ে ফিল্টার, সর্ট, পার পেজ
   - বাল্ক সিলেক্ট করে একসাথে Enable/Disable
   - ডুপ্লিকেট (কপি) তৈরি

   পরবর্তী ধাপ: অ্যাট্রিবিউট তৈরি করার পর Category Attributes পেজে গিয়ে প্রতিটি ক্যাটাগরির জন্য কোন অ্যাট্রিবিউট ব্যবহার হবে সেটা সিলেক্ট করুন।

২) Category Attributes
   লিংক: /sajaladminopu/category/attributes

   কী কাজ:
   - Product Attributes এ যেসব অ্যাট্রিবিউট বানিয়েছেন, সেগুলো কোন কোন ক্যাটাগরিতে ব্যবহার হবে সেটা এখানে সেট করবেন।
   - উদাহরণ: Fashion ক্যাটাগরিতে Size ও Color চালু করুন; Electronics এ Storage, RAM চালু করুন।

   প্রতিটি ক্যাটাগরির টেবিলে:
   - Use: এই ক্যাটাগরির জন্য অ্যাট্রিবিউট ব্যবহার করলে টিক দিন
   - Required: প্রোডাক্ট এডিটে এই ফিল্ড বাধ্যতামূলক করতে চাইলে টিক দিন
   - For variant: প্রোডাক্ট ভেরিয়েন্ট (সাইজ/কালার অনুযায়ী প্রাইস বা স্টক) বানাতে ব্যবহার করলে টিক দিন
   - Order: কত নম্বরে দেখাবে (কম সংখ্যা = আগে)

   ব্যবহারের ধাপ:
   ১) আগে Product Attributes পেজ থেকে অ্যাট্রিবিউট তৈরি করুন (Size, Color ইত্যাদি)
   ২) তারপর এই পেজে (Category Attributes) প্রতিটি ক্যাটাগরির কার্ডে টিক দিয়ে সিলেক্ট করুন কোন অ্যাট্রিবিউট ব্যবহার হবে
   ৩) "Save for this category" বাটন ক্লিক করুন

   যদি কোনো অ্যাট্রিবিউট না থাকে তাহলে এই পেজে "No attributes yet" দেখাবে এবং Product Attributes পেজে যাওয়ার লিংক দেওয়া থাকবে।
